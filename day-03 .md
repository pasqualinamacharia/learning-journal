# Day 3 — Branches and Commits

Today I learned how GitHub branches work.

## What I learned

A branch allows me to work on changes separately from the main branch.

I learned that:
- main is the primary branch.
- A separate branch can be used to work on new changes.
- A commit records a change to the project.
- Changes made on a branch can later be merged into main.
