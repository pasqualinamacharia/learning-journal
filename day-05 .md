**How to Write in Markdown: The Secret to Open Source Docs**

When contributing to open-source projects, you will rarely use Microsoft Word or Google Docs.
Instead, open-source communities rely on Markdown.

Markdown is a lightweight markup language that allows you to format plain text using simple symbols. 
Because it avoids complex coding, 
It ensures that project documentation remains clean, readable, and easy to update directly on GitHub.

Here is a quick starter guide to mastering the basics of Markdown.

1. Organizing Content with Headers
To create a heading, simply place a hash symbol (#) before your text.
The number of hash symbols determines the size of the header:
- # Heading 1 (Used for the main title)
- ## Heading 2 (Used for major sections)
- ### Heading 3 (Used for Subsections)

2. Adding Emphasis to Text
You can easily draw a reader's attention to key terms by using asterisks (*):
- Bold Text: Wrap your words in double asterisks. Example: **Important** becomes **Important**.
- Italic Text: Wrap your words in single asterisks. Example: *Note* becomes _Note_.

 3. Creating Punchy Lists
  Clean documentation relies heavily on lists to breakdown complex instructions.
  - For bulleted lists, place a single asterisk * or a hyphen - before each item.
  - For numbered lists, simply type the number followed by a period (e.g., 1., 2.).

  4. Sharing Links and Code Snippets
    Open-source documents frequently link to external resources or showcase technical commands:
- Links: Place the clickable text in square brackets and the URL in parentheses.
      Example: [Outreachy]
      (https://outreachy.org)
 - Code: To highlight a specific keyboard command or file name within a sentence, wrap it in backticks (').
       Example: 'README .md' turns into README .md.

Summary
Markdown strips away the distraction of styling menus, letting you focus entirely on explaining concepts clearly.
Master these four basic rules, and you are ready to write professional open-source documentation!
